# Central completeness center

Read-only worklist under Accountancy and Cockpit directory. The administrator explicitly chooses an existing entity/year; only that administration is loaded. Reuses the validated annual source, private document links, invoice metadata controls and supplier identity signals. No migration, new permissions, payment or source mutation.

Groups invoice issues into one row and supplier warnings once per supplier; archive reviews and outstanding annual checklist sections remain separate records. Filters and 30-item pages preserve the selected administration. A missing/invalid selection performs no annual inspection; a source failure displays an unavailable result, never zero outstanding items. Counts refer to worklist items, not unique invoices or statutory completeness.

Original attachments open the invoice's existing upload/link screen; document reviews open the document; cost review links pass an exact draft filter, including invoices beyond page one. Supplier correction opens the existing supplier/relationship register. Existing source screens retain all validation and audit controls.

Scope is registered annual data only: cannot detect invoices never entered. Entity-level overhead does not need a property. Duplicate identity/invoice signals require manual verification. Bank reconciliation remains deferred and is deliberately omitted from this worklist. No bank, VAT or tax determination, supplier merge, automatic approval or external mail.

Auth confirmation/recovery provider templates remain deferred. Production authorization follows tests, preview and live verification, retaining the existing pilot release allowlist.
