# Standalone invoice creation — admin improvement step 2

Invoices → Create invoice / review drafts lets an active administrator select an issuing entity and customer, verify an invoice-specific billing address, enter subject/reference/attention/tax details, due date, payment terms and up to 30 quantity/unit-price/VAT lines. VAT is explicitly chosen by the administrator; no jurisdiction or tax treatment is inferred. Database decimal arithmetic rounds each net line and VAT to cents.

Saving produces an immutable, auditable concept snapshot without consuming a number. Review the on-screen totals and draft PDF, then explicitly confirm issue. A draft needing changes is cancelled with a reason and replaced by a corrected draft; neither deleting evidence nor editing issued invoices is supported. Issuance locks the draft and existing issuer counter, is idempotent, checks all existing invoice sources for number collisions and consumes one shared issuer number only after successful insert. Repeated issue returns the existing invoice.

Issued invoices immediately join Invoices/Cockpit, provide PDF download, accept protected partial/full receipt registrations and append-only reversals, and enter the existing accountant export with known net/VAT. This release does not send invoice emails; download and delivery are separate. Automated controlled delivery is not part of this implementation. Credit notes remain roadmap step 4.

Private-person PDF snapshots suppress logos and never add MZS branding, rental subtitles or rental payment-period wording. Registered issuer identity/address/bank/tax data remain. The existing rental renderer retains its original default behavior. Synthetic service PDF rendered and visually inspected, including text extraction for totals and absence of MZS branding.
