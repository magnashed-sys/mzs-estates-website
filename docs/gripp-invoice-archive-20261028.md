# Historical Gripp invoice archive

Accountancy / Historical invoices preserves imported invoice headers and their complete original CSV fields, with issue-year, literal text and balance/credit filters. All source years remain available. The default year follows Europe/Madrid. Full-selection controls are calculated server-side in one stable snapshot; paginated lists and filtered CSV exports never substitute loaded-page totals for complete totals. Detail screens preserve filter return links.

This is an archive, not a new invoice or bookkeeping posting. Original source paid/open values remain snapshots without payment dates. Negative documents and zero invoices are retained. VAT is the arithmetic difference between exported gross and net, with no inferred rate. Currency EUR is explicitly marked as an import setting because the source has no currency field. Unknown export timestamps remain null. Source names, original dates (issue/report/draft/due), descriptions and text credit references are retained. There is no automatic relation/property matching, revenue recognition, bank entry, mail, original-PDF reconstruction or addition to financial Cockpit/accountant sales totals.

The immutable batch records original-byte SHA-256, source file identity, columns, authorization, import time and all expected totals. Deferred reconciliation makes the whole batch atomic. Each source row is validated and its searchable fields derived from its original JSON, not independently supplied normalized values. Active-admin RLS permits read only; no application role can insert/update/delete records. Controlled imports use the administrative connection with explicit provenance. Unique issuer/number, source hash and source row prevent duplicate imports. The shared existing issuer lock now also prevents newly issued invoices from reusing archived numbers; current invoice sequences remain unchanged.
